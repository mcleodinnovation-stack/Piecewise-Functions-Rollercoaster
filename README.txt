ALGEBRA 2 COASTER LAB — META QUEST 3 TEST

1. Test locally on a laptop by opening index.html with a browser and internet access.
2. To test on Quest 3, upload index.html to a static HTTPS host (e.g. GitHub Pages or Netlify).
3. In the Meta Quest Browser, open the HTTPS URL. Wait for the Enter VR button to activate.
4. Clear your space and remain seated. Click Enter VR. Use the controller trigger to start/pause the ride.
5. Exit with the Quest system controls.

Important: This is an unverified Quest prototype. Actual headset testing is required.
Requires a network connection to load Three.js from CDN. Does not store student information or upload equations.

Equations must be continuous, nonnegative, start at t=0, and be in the form start,end,slope,intercept.
VR comfort: Use seated mode, short sessions, and stop immediately if you feel unwell.
